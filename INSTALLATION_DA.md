# Installation

1. Upload indholdet af denne mappe, så `setup.php` ligger i dokumentroden.
2. Sørg for PHP 8.1+ med `pdo_mysql` og `openssl`.
3. PHP-processen skal kunne skrive til `config/` og `storage/`.
4. Åbn `setup.php` og indtast ekstern databasevært, port, database, bruger og adgangskode.
5. Databasebrugeren skal have adgang fra webserverens IP-adresse.
6. AI-botter oprettes efter installation; de indtastes ikke i setup.
